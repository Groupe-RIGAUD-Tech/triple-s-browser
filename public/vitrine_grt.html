Spécifications Techniques : Comment rendre un site compatible SSS ?

Le protocole Triple S (Secure Static Protocol) applique le principe de réduction maximale de la surface d'attaque. Pour qu'un site d'entreprise soit éligible à l'annuaire souverain, son code doit respecter 4 règles :

  • Zéro exécution côté client : Toutes les balises <script> et <iframe> sont physiquement rejetées par le moteur réseau (Erreur 52).
  • Architecture HTML5 / CSS3 pure : La mise en page doit être générée côté serveur (SSR) ou écrite en HTML statique, sans dépendre d'un framework dynamique (React/Vue non pré-rendu).
  • Images autonomes : Sur le réseau sss://, les visuels et logos doivent être intégrés en vectoriel <svg> ou encodés en data:image/png;base64 directement dans le document HTML.
  • Interactions sécurisées : Les prises de contact s'effectuent via le protocole standard mailto: et, dès la V2, via la signature cryptographique native du navigateur.
